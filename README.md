# AstrBot OpenAI 原生能力

让 AstrBot 在聊天中搜索网页、生成图片，或按要求修改用户发来的图。搜索和生图可以各用一个供应商。生图在后台运行，机器人先回复任务 ID，完成后把图片发回原会话。上游支持原生 GIF 时，也可以生成动图。

各版本的功能变化和升级提示见[更新日志](CHANGELOG.md)。

## 快速开始

1. **安装插件**。需要 AstrBot 4.29.4+ 和 Python 3.12+。在 AstrBot 插件管理中选择从链接安装，填入 `https://github.com/timeance/astrbot_plugin_openai_native`。也可上传完整源码 ZIP。手动部署时请在 AstrBot 的 Python 环境安装 [requirements.txt](requirements.txt) 中的依赖。
2. **选择供应商**。打开插件配置，按需启用搜索和生图。已有供应商可选「当前会话供应商」或「指定供应商」。独立使用 API 时，选「手动配置」，到插件页面填写 API 地址、密钥和模型。**生图必须填写上游支持的图片模型**，即使复用聊天供应商也要填。
3. **检查配置**。在插件页面保存连接设置后，回到插件管理手动重载。管理员可在聊天里发送 `/onative status` 查看配置状态，这一步不消耗搜索或生图额度。
4. **试用已开启的功能**。私聊发送「帮我搜索 AstrBot 更新日志」，或用 `/生图 一张雨夜街景的水彩画` 提交第一张图。搜索和生图可能产生上游费用。

自然语言调用需要聊天模型支持工具调用，并在当前人格中启用相应工具。固定生图命令可直接使用。OpenAI、NewAPI、Sub2API 的连接示例见[配置指南](docs/CONFIGURATION.md)。

## 网页搜索

私聊或在群里唤醒机器人后，可以说「帮我搜索 AstrBot 更新日志，总结最近的变化」。默认只在用户明确要求时搜索。想让模型自行决定何时联网，可在「搜索设置 → 何时搜索」选择「用户要求，或由模型按需决定」。

一次默认查 1 个主题，最多取 3 条结果。如果希望机器人在回答中给出网页地址，在高级搜索设置中打开「附带来源链接」。也可以用 `/onative search AstrBot 更新日志` 直接查看搜索结果。

## 生图、改图和 GIF

| 想做什么 | 怎么发 |
| --- | --- |
| 画一张静态图 | `/生图 一张水彩风格的城市明信片`，默认输出 PNG |
| 指定比例、分辨率和数量 | `/生图 城市明信片 16:9 2K 2` |
| 指定尺寸和文件格式 | `/生图 城市明信片 --尺寸 1024x1024 --格式 webp` |
| 使用已保存的绘图预设 | `/生图 城市明信片 --预设 水彩` |
| 修改已有图片 | 附上或引用原图，发送「把这张图改成水彩风格」 |
| 参考 QQ 用户头像 | 在 OneBot 群聊中发送 `/生图 参考 @某人 的头像画一张像素风肖像`，用聊天软件实际 @ 对方 |
| 生成原生 GIF | `/生动图 让画面里的招牌闪烁 --帧数 9 --帧时长 200`，帧时长单位为毫秒 |
| 查看或取消任务 | `/生图任务` 列出本人在当前会话的任务，`/生图任务 <任务ID>` 查详情，`/生图取消 <任务ID>` 申请取消 |

固定尺寸与「比例 + 分辨率」二选一。一次最多请求 4 张，实际数量受管理员设置和上游限制。若其他插件占用了同名命令，可改用 `/onative image` 或 `/onative gif`，参数写法相同。

编辑时优先附图或引用原消息。要沿用本人在当前会话的近期图片，请明确说「参考上一张图」。动图作为参考时只取首帧。QQ 头像参考需要 `aiocqhttp` 适配器。管理员可在「生图设置 → 图片连接」开启「群聊仅在 @本机器人时生效」。开启后，群聊里即使要参考其他人的头像，也要同时 @ 本机器人。

GIF 默认关闭，需在插件页面启用，并使用支持原生 GIF 的 Images API、模型和账号。默认 9 帧、每帧 200 毫秒，可设 2 至 16 帧、每帧 20 至 2000 毫秒。

## 供应商设置

| API 来源 | 适用场景 |
| --- | --- |
| 当前会话供应商 | 提交时使用当前会话所选的供应商。聊天后来切换到备用供应商，已提交的任务仍使用原连接。 |
| 指定供应商 | 固定使用 AstrBot 中已有的供应商。例如聊天用 A、搜索用 B、生图用 C。 |
| 手动配置 | 搜索或生图使用单独的 API 地址、密钥和模型。密钥支持环境变量引用。 |

网页搜索可用 Responses 或 Alpha Search，静态生图可用 Images 或 Responses。使用 Responses 生图时要区分宿主模型和图片模型。通过 NewAPI、Sub2API 接入时，请确认所选渠道和账号支持对应接口。[配置示例](docs/CONFIGURATION.md) · [兼容范围](docs/COMPATIBILITY.md)

## 额度与任务管理

| 默认每日额度 | 群聊每人（跨群累计） | 每个群 | 私聊每人 |
| --- | ---: | ---: | ---: |
| 搜索 | 20 次 | 200 次 | 20 次 |
| 生图 | 3 张 | 30 张 | 3 张 |

命令和自然语言调用共用额度。例如，同一用户在 A 群提交了 2 张图，当天在 B 群最多还能提交 1 张，前提是 B 群仍有额度。私聊单独计算。发送 `/onative quota` 可查看剩余额度。额度默认按 UTC 日期重置，可在「通用设置」中调整时区。`0` 表示不限额，旧配置若用 `0` 禁用某项功能，请改用对应的启用开关。

图片请求一旦提交给上游就占用额度，包括上游审核拒绝的请求。排队时取消可释放预占额度。任务失败时，机器人会把任务 ID 和原因发回会话。遇到超时、断线或结果未送达，先查任务状态，避免重复提交产生费用。

管理员可以在插件页面的「任务」查看生成和投递状态，在「图库」查看已保存的图片。图片默认保留 7 天，任务记录默认保留 30 天，待核对任务会继续保留。备份时请包含 `data/plugin_data/astrbot_plugin_openai_native`。需要排查工具未触发或投递失败时，可在概览开启诊断日志。日志开关保存后立即生效。

| 管理员命令 | 用途 |
| --- | --- |
| `/onative status` | 查看连接配置和已记录的能力状态 |
| `/onative probe <能力> confirm` | 实际调用上游测试能力，可能计费。例如用 `generate:png` 测试静态生图 |
| `/onative retry-download <任务ID>` | 从原结果地址重新下载，避免再次生图 |
| `/onative reconcile <任务ID> <实际文件数>` | 核实上游执行结果后，结算待核对任务 |
