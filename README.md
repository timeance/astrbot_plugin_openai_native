让 AstrBot 在聊天中搜索网页、生成图片，或按要求修改参考图。搜索和生图可以各用一个供应商。生图在后台运行，机器人先返回任务 ID，完成后把图片发回原会话。上游支持原生 GIF 时，也可以生成动图。

各版本变更与升级说明见 [更新日志](CHANGELOG.md)。

## 快速开始

1. **安装插件**：需要 AstrBot 4.29.4+ 与 Python 3.12+。在 AstrBot 插件管理中通过链接安装 `https://github.com/timeance/astrbot_plugin_openai_native`，或上传完整源码 ZIP。手动部署请先在 AstrBot 的 Python 环境中安装 [requirements.txt](requirements.txt) 中的依赖。
2. **配置供应商**：打开插件配置，按需启用搜索与生图。可直接选择「当前会话供应商」或「指定供应商」；如需独立接入 API，选择「手动配置」并在插件控制台填写接口地址、密钥与模型。**生图必须显式填写上游支持的图片模型**，即使复用聊天供应商也需填写。
3. **重载并检查**：在插件控制台保存连接设置后，回到插件管理手动重载插件。管理员可在聊天中发送 `/onative status` 检查配置状态（不消耗额度）。
4. 私聊发送「帮我搜索 AstrBot 更新日志」，或使用 `/生图 一张雨夜街景的水彩画` 提交第一张图片。实际搜索和生图可能产生上游费用。

> 自然语言调用需聊天模型支持工具调用，且在当前人格中启用对应工具；固定命令（如 `/生图`）可直接使用。OpenAI、NewAPI、Sub2API 的接入示例见 [配置指南](docs/CONFIGURATION.md)。

## 网页搜索

私聊或在群聊中唤醒机器人后，直接发送「帮我搜索 AstrBot 更新日志，总结最近的变化」即可。默认仅在用户明确要求时触发搜索；如需模型按需自行决定，可在控制台「搜索设置 → 何时搜索」中切换为「用户要求，或由模型按需决定」。

单次默认查询 1 个主题、最多返回 3 条结果。若希望回答附带网页地址，可在高级搜索设置中开启「附带来源链接」。也可以使用 `/onative search AstrBot 更新日志` 直接查看搜索结果。

## 生图、改图与原生 GIF

| 场景 | 示例命令 / 说法 |
| --- | --- |
| 生成静态图 | `/生图 一张水彩风格的城市明信片`（默认输出 PNG） |
| 指定比例、分辨率与数量 | `/生图 城市明信片 16:9 2K 2` |
| 指定尺寸与格式 | `/生图 城市明信片 --尺寸 1024x1024 --格式 webp` |
| 使用绘图预设 | `/生图 城市明信片 --预设 水彩` |
| 修改已有图片 | 附图或引用原图，发送「把这张图改成水彩风格」 |
| 参考 QQ 头像 | 在 OneBot 群聊中发送 `/生图 参考 @某人 的头像画一张像素风肖像`（直接 @ 对方） |
| 生成原生 GIF | `/生动图 让画面里的招牌闪烁 --帧数 9 --帧时长 200`（单位：毫秒） |
| 查询或取消任务 | `/生图任务` 列出本人在当前会话的任务，`/生图任务 <任务ID>` 查详情，`/生图取消 <任务ID>` 申请取消 |

- **参数与命令冲突**：固定尺寸与「比例 + 分辨率」二选一；单次最多请求 4 张（受管理员设置与上游限制）。如命令与其他插件冲突，可改用 `/onative image` 或 `/onative gif`（参数一致）。
- **参考图**。改图时可附图、引用原消息，或说「参考上一张图」沿用本人在当前会话的近期图片。使用动图作参考时取首帧。
- **群聊 @**。QQ 头像参考需要 `aiocqhttp` 适配器。在「生图设置 → 图片连接」开启「群聊仅在 @本机器人时生效」后，要参考群友头像，请在同一条消息里同时 @ 机器人和该群友。
- **原生 GIF**：默认关闭，需在插件控制台启用并配合支持原生 GIF 的 Images API、模型与账号。默认 9 帧、每帧 200ms，支持 2–16 帧、每帧 20–2000ms。

## 供应商配置模式

| API 来源 | 说明 |
| --- | --- |
| 当前会话供应商 | 提交时自动沿用当前会话所选供应商；后续切换备用供应商不影响已提交任务。 |
| 指定供应商 | 固定绑定 AstrBot 中已配置的供应商，适合聊天、搜索、生图分开指定模型。 |
| 手动配置 | 单独填写 API 地址、密钥与模型（密钥支持环境变量引用）。 |

网页搜索支持 Responses 或 Alpha Search，静态生图支持 Images 或 Responses。使用 Responses 生图时，图片模型需明确填写，宿主模型可沿用所选供应商的模型。手动配置时两者都要填写。通过 NewAPI、Sub2API 接入时，请确认渠道和账号支持所选协议。详见[配置指南](docs/CONFIGURATION.md)与[兼容范围](docs/COMPATIBILITY.md)。

## 额度、任务与管理

| 默认每日额度 | 群聊每人（跨群累计） | 单群总额 | 私聊每人 |
| --- | ---: | ---: | ---: |
| 搜索 | 20 次 | 200 次 | 20 次 |
| 生图 | 3 张 | 30 张 | 3 张 |

- **额度统计与重置**：命令与自然语言共用额度；群聊个人额度跨群累计，私聊独立计算。发送 `/onative quota` 查看剩余额度。默认按 UTC 每日重置，可在「通用设置」中修改时区；`0` 表示不限额。
- **跨群额度**。按默认设置，同一用户在 A 群提交了 2 张图，当天在 B 群还能提交 1 张，前提是 B 群仍有额度。
- **计次与失败处理**。生图请求提交给上游即占用额度，包括审核拒绝。排队时取消可释放预占额度。任务失败时，机器人会发回任务 ID 和原因。超时或图片未送达时，先查询原任务。上游已生成图片时，管理员可用 `retry-download` 重新下载，避免重复计费。
- **控制台与维护**：管理员可在控制台「任务」页查看执行与投递状态，在「图库」页浏览已保存图片（图片默认保留 7 天，任务记录保留 30 天，待核对任务不受清理影响）。数据位于 `data/plugin_data/astrbot_plugin_openai_native`，备份时请一并包含。排查问题可在「概览」开启诊断日志（保存后立即生效）。

| 管理员命令 | 说明 |
| --- | --- |
| `/onative status` | 查看当前连接配置与能力状态 |
| `/onative probe <能力> confirm` | 实测上游接口能力（真实请求，可能计费；如 `generate:png`） |
| `/onative retry-download <任务ID>` | 从原结果地址重新下载图片，不重新生图 |
| `/onative reconcile <任务ID> <实际文件数>` | 核实上游结果后，手动结算待核对任务 |

## 开发者接口与许可

插件注册了 `openai_web_search`、`openai_image`、`openai_image_task` 三个聊天工具，同时向其他 AstrBot 插件开放 Python API。详见 [公共 API](docs/PUBLIC_API.md) · [实现结构](docs/ARCHITECTURE.md) · [验收清单](docs/VALIDATION.md)。
